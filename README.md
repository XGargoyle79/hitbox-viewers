# hitbox-viewers

A collection of LUA scripts for displaying hitboxes in emulators like MAME or FBNeo.

Just download the script version for your favorite emulator and enjoy labbing!

Scripts are compatible with MAME 0.287 and Fightcade FBNeo v0.2.97.44-55, but they many not work on other emulators or forks.

##**AI usage disclaimer:** Scripts come with a frame delay feature, which you can configure in case the boxes are drawn earlier or later than the corresponding sprite frame. Such feature has been entirely coded through AI assistance.
